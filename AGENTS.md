# Agent instructions

If you were asked to install ArchiBridge or connect an AI app to Archicad, follow [INSTALL.md](INSTALL.md).

Repository layout:

- `install.ps1`, `uninstall.ps1`: Windows PowerShell 5.1+ scripts. Keep them ASCII-only and compatible with Windows PowerShell 5.1 (no `??`, no ternary, no `&&`).
- `src/archibridge/`: the MCP server. `client.py` talks to Archicad, `policy.py` decides what may run, `catalog.py` searches commands, `server.py` defines the tools.
- `src/archibridge/data/catalog.json`: generated by `scripts/update_catalog.py`. Never edit it by hand.
- `src/archibridge/skills/<name>/SKILL.md`: skills served by `archicad_get_skill`. Add a new one to `SKILLS` in `server.py`.
- `tests/`: run with `uv run --group dev pytest`. They use a fake Archicad and need no real one.

To move to a new Tapir release: run `python scripts/update_catalog.py <version> <archicad release>`, then update `$TapirVersion` and `$TapirHashes` in `install.ps1` from the release's asset digests.
