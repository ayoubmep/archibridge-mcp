# Agent instructions

If you were asked to install ArchiBridge or connect an AI app to Archicad, follow [INSTALL.md](INSTALL.md). It covers Windows and macOS: check the operating system first, then follow its section.

Repository layout:

- `install.ps1`, `uninstall.ps1`: the Windows installer and uninstaller, for Windows PowerShell 5.1+. Keep them ASCII-only and compatible with Windows PowerShell 5.1 (no `??`, no ternary, no `&&`).
- `install.sh`, `uninstall.sh`: the macOS installer and uninstaller. They do the same steps as the PowerShell scripts, with Mac locations, and print the same messages. Keep them ASCII-only and compatible with the bash 3.2 that ships with macOS (no associative arrays, no `mapfile`, no `${var,,}`, no empty `"${array[@]}"`), and keep `shellcheck` clean.
- `src/archibridge/`: the MCP server. `client.py` talks to Archicad, `policy.py` decides what may run, `catalog.py` searches commands, `server.py` defines the tools. It is plain Python and runs on Windows and macOS.
- `src/archibridge/data/catalog.json`: generated by `scripts/update_catalog.py`. Never edit it by hand.
- `src/archibridge/skills/<name>/SKILL.md`: skills served by `archicad_get_skill`. Add a new one to `SKILLS` in `server.py`.
- `tests/`: run with `uv run --group dev pytest`. They use a fake Archicad and need no real one.
- `.github/workflows/installers.yml`: CI. It runs the tests on Windows and macOS, parses the PowerShell scripts with Windows PowerShell 5.1, runs shellcheck, and runs `install.sh` and `uninstall.sh` for real on macOS runners (Apple silicon and Intel) against a fake Archicad folder. It can't cover a real Archicad or the macOS password prompt.

To move to a new Tapir release: run `python scripts/update_catalog.py <version> <archicad release>`, then update the version and hashes in both installers from the release's asset digests: `$TapirVersion` and `$TapirHashes` in `install.ps1` (the `TapirAddOn_AC<version>_Win.apx` files), `TAPIR_VERSION` and `tapir_hash` in `install.sh` (the `TapirAddOn_AC<version>_Mac.zip` files).
